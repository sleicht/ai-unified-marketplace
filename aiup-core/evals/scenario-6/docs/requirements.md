# Library Management System Requirements

## Functional Requirements

| ID | User Story | Priority | Status |
|---|---|---|---|
| FR-001 | As a Library Member, I want to search the catalogue by title, author, or ISBN so that I can find available books quickly. | High | Approved |
| FR-002 | As a Library Member, I want to borrow a book so that I can take it home and read it. | High | Approved |
| FR-003 | As a Library Member, I want to return a borrowed book so that other members can access it. | High | Approved |
| FR-004 | As a Library Member, I want to renew my loan so that I can keep a book for longer without returning it first. | Medium | Approved |
| FR-005 | As a Library Member, I want to reserve a book currently on loan so that I am notified when it becomes available. | Medium | Approved |
| FR-006 | As a Librarian, I want to register new books so that members can discover and borrow them. | High | Approved |
| FR-007 | As a Librarian, I want to process overdue returns and apply fines so that borrowing policy is enforced. | High | Approved |
| FR-008 | As a Librarian, I want to manage member accounts so that access to library services is controlled. | High | Approved |

## Non-Functional Requirements

| ID | Category | Requirement | Status |
|---|---|---|---|
| NFR-001 | Performance | Catalogue searches return within 2 seconds for up to 50,000 books. | Approved |
| NFR-002 | Availability | The system is available 99.5% during opening hours. | Approved |

## Constraints

| ID | Constraint | Status |
|---|---|---|
| C-001 | The system runs on the library's existing Linux servers. | Approved |
| C-002 | The system complies with GDPR. | Approved |
