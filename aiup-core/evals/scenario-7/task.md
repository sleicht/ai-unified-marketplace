# Update the Project Tracker Use Case Diagram

## Problem/Feature Description

The Project Tracker team maintains a living catalogue and embedded Mermaid diagram in `docs/requirements.html`. Compliance requested an Auditor role. The product manager added FR-004 and FR-005, but the diagram still covers only UC-001 through UC-003.

Extend the existing diagram so the new requirements are represented while existing use cases and catalogue content remain intact.

## Output Specification

Update only the Mermaid block under `#use-case-diagram` in `docs/requirements.html`.

Do not delete or renumber any existing use cases. New use cases should continue the existing UC identifier sequence without gaps or duplicates.
